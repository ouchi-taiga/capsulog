## 構成

各ディレクトリの README に、そこでの決まりを書いている。

収集バッチを Workers ではなく GitHub Actions で動かすのは、奇譚クラブの953件を1秒間隔で回すと約16分かかり、Workers の CPU 時間に収まらないため。

インフラは全て無料枠で運用する。

## 開発環境

Dev Container で開発する。ホスト側に Node や Rust を入れる必要はない。

VS Code で「Reopen in Container」を実行すると、必要なものが揃った状態で起動する。

### バージョン

**固定せず最新に追従する。** 個人開発で長く放置すると追従コストが上がるため、常に最新を使う。

| | 指定 | 供給元 |
|---|---|---|
| Node | LTS | devcontainer feature |
| Rust | 最新安定版 | devcontainer feature |
| Python | 最新安定版 | uv が管理する |
| uv | 最新 | 公式イメージからコピー |

Rust には `wasm32-unknown-unknown` ターゲットを入れている。Workers が WASM 上で動くため。

依存の更新で壊れたときは、バージョンを固定するのではなく原因を直す。固定するのは直せない理由があるときだけ。

### Cloudflare の認証

コンテナ内で一度だけ実行する。認証情報は volume に残るため、コンテナを作り直しても消えない。

```bash
npx wrangler login
```
