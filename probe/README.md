# probe

各メーカーからデータが取れることを確認するスクリプト。

収集バッチとは実装を共有しない。**バッチ側のバグと、メーカー側の仕様変更を切り分けるため。** 収集が中止されたときは、まずこれを走らせて原因がどちら側かを判断する。

## 実行

```bash
uv run probe/kitan.py
uv run probe/tarlin.py
uv run probe/bandai.py
```

各スクリプトは数十件を取得し、欠損と値の分布を出力する。取得件数を絞ってあるため、相手サーバーへの負荷は小さい。

## 出力の見方

`欠損: なし` であれば構造は生きている。欠損が出た場合は、そのメーカーのHTMLかAPIが変わった可能性が高い。

ターリンの発売月は常時8%前後欠損する。これはメーカー側がデータを入れていないためで、異常ではない。

## ターリンの証明書

ターリンのサーバは中間証明書を配信していない。リーフ証明書を2枚返す設定のため、ブラウザ以外のHTTPクライアントは証明書検証に失敗する。

`globalsign-intermediate.pem` で補っている。証明書が更新されたら差し替える。

## 依存

標準ライブラリのみ。外部パッケージを追加しない。**検証スクリプトが依存で壊れると、切り分けの役に立たなくなるため。**
