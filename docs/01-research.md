# カプセルトイ向けサービス 事前調査レポート

作成日: 2026-08-30
調査方法: Web調査（4領域を並行調査）
目的: 個人開発でカプセルトイ関連サービスを作る際の事業性検証

---

## エグゼクティブサマリ

**判定: 条件付きGO**

当初構想（入荷情報を追うアプリ）は、以下3つの理由により**そのままでは成立しない**。

1. 店舗別の入荷日は**構造的に存在しない**（メーカーも店舗も正確に知らない）
2. 設置場所・在庫検索は**公式3社が無料提供済み**
3. 同コンセプトの**個人開発先行者が壁に当たっている**（本人が公表）

一方で、以下の空白が確認された。

- **日本商品対応のラインナップ単位コレクション管理**（＝全5種中3種所持、シークレット未所持の管理）
- **ダブり交換マッチング**

市場は6年で5倍に成長中（385億円 → 1,960億円）。母数は十分だが、**課金相場が月額350〜480円と低く**、目標月5〜10万円には MAU 3,000〜12,000 が必要。

## 2. 店舗別入荷情報の実在性

### 2.1 結論: 店舗別の入荷日は公式情報として存在しない

**理由は「メーカーが出し渋っている」のではなく「構造的に誰も知り得ない」から。**

大手2社が自ら免責している。

タカラトミーアーツ 発売カレンダー:
> ※取扱い店舗によって店頭展開日が異なります。お取扱い時期については各店舗にご相談ください。
> ※出荷予定日の3日目以降の週で表記しています。

バンダイ 発売スケジュール:
> ※発売時期は地域や店舗によって異なる場合があります。

**「発売日」＝メーカーの出荷日であり、店頭に並ぶ日ではない。粒度は週単位。**

### 2.2 原因: 巡回業者による補充構造

ガチャの補充・集金は店舗ではなく**外部の巡回業者**が実施。担当地区を一巡する期間だけ差が出る。

Yahoo!知恵袋の証言（※ユーザー証言であり公式統計ではない）:
> ひとりで担当地区を2週間くらいかけて回るので、最速と最後では入荷が最悪2週間違うのです。

さらに**店員自身も正確に把握していない**という報告が複数。「明日入荷予定」と言われたのに数時間後には既に投入済みだった事例あり。

### 2.3 専門店チェーンの情報公開状況

| チェーン | 店舗別入荷情報 | 形式 | 備考 |
|---|---|---|---|
| ガシャポンのデパート | 部分的 | 店舗別X | 公式FAQで「発売時期の異なる店舗もございます」と明記 |
| ガチャガチャの森 | なし | 全店共通X/Instagram | 入荷情報ページなし |
| #C-pla | なし | 公式アプリ | **全店共通通知**。在庫検索機能は非搭載（レビューで要望が出ている段階） |
| ドリームカプセル | 部分的 | 店舗別X | 内容はほぼ事後報告 |

**重要**: 店舗別Xが存在しても投稿はほぼ**事後報告**（「入りました」）で、事前の入荷予定日告知ではない。

### 2.4 ユーザーの実際の困り方

Yahoo!知恵袋:
> みなさんどうやってガチャの入荷情報見てるんですか？私の近くにある店舗は全然X動かしていないので、入荷情報わかりません。

**店舗Xは大型店・都心店に偏っており、地方店舗は情報発信していない** → 地方ユーザーは構造的に情報から締め出されている。

現状の解決策は、①店舗別Xのフォロー ②情報アカウントのフォロー ③店舗への電話 ④ユーザー投稿型サイト の組み合わせで、いずれも確実性がない。

## 3. 競合分析

### 3.1 メーカー公式・店舗系（最大の競合）

| サービス | 提供元 | 機能 | Platform | 料金 |
|---|---|---|---|---|
| **ガシャどこ？PLUS** | バンダイ | 商品/店舗の二軸検索。**在庫を○（11個以上）/△（10個以下）で表示** | Web | 無料 |
| **ガチャナビ** | タカラトミーアーツ | GPS店舗検索・**約5,000店舗**、地図、商品検索、デジガチャ | iOS/Android | 無料 |
| **gashacoco公式アプリ** | ハピネット | **POS連動でリアル在庫検索**、スタンプカード、店舗検索 | iOS/Android | 無料 |

**重要**: ガシャどこ？PLUSは設置場所だけでなく**在庫状況も表示**する。ただし自社商品のみ・登録店舗のみ・非リアルタイムで、「実際の在庫と異なる場合がある」と自ら注記。gashacocoはPOS連動で精度が高いが**自社チェーン限定**。

→ **「どこで買えるか」領域は公式に取られたと考えるべき。ここでは戦わない。**

### 3.2 新商品情報・入荷情報（レッドオーシャン）

がちゃなび、Gacha Post、ガチャガチャアイランド、Gacha Paradise（SmartNews/Gunosy/Spotifyへ配信、多言語）、カプセルトイ入荷カレンダー（カレンダー＋マイリスト＋交換掲示板）、電撃ホビーウェブ、各メーカー公式カレンダー。

**完全に飽和している。**

### 3.3 コレクション管理

**日本語のカプセルトイ専用コレクション管理アプリは見つからなかった。**

ただし2つの脅威が存在する。

**汎用コレクション管理アプリ**

- My図鑑（プレミアム **月額350円**、評価4.6/5・1,170件）
- グッズリスト（持ってる/欲しい/注文中の3状態、無料10件まで）
- ウマカン、monoca 2、モノコレ、Kiroku

**英語圏のブラインドボックス専用トラッカー（重要）**

- **Blind Box Tracker**: 2,000体以上、所有/欲しい/トレード/シークレット/ダブり数量管理、有料Collectors Clubで再入荷通知
- **Collectsy**: **ダブりマッチングによるトレード相手発見機能つき**
- Bubuspace

→ いずれも **Sonny Angel / SMISKI / POP MART 中心で、バンダイ・タカラトミーアーツ・キタンクラブなど日本のガチャは対応ブランドに含まれていない**。これが決定的な差。

|---|---|---|

### 3.5 個人開発の先行事例（最重要の教訓）

**ガチャマニア／ガチャマップ**（たみな涼介氏、2023年4月、iOS/Android）
ガチャ専用SNS＋目撃情報投稿マップ＋GETアイテムのコレクション記録。**想定コンセプトに最も近い先行例**。

開発者本人がnoteで以下を明記している。
> ただ場所がわかるだけでは必要とされない

壁にぶつかりSNS機能で差別化した経緯が公表されている。

### 3.6 空白地帯

1. **日本のガチャに対応したラインナップ単位のコレクション管理** ← 最大の空白
   海外勢は仕組みを持つが日本商品を持たず、日本勢は情報を持つが管理機能を持たない。**「商品DB × コンプリート率管理」の交差点が空いている。**

2. **情報→記録→交換の分断**
   新作情報（がちゃなび）、在庫（ガシャどこ？PLUS）、交換（ガチャトレ）が全て別サービス。「気になる→買った→ダブった→交換」が一本の線で繋がっていない。

3. **メーカー横断の統合商品データベース** — 型番・シークレット・ラインナップ単位のものは不在

4. **ダブり資産の可視化** — メルカリに週16,500件流れているのに「自分のダブりが今いくらか」を出すサービスがない

## 4. 技術的実現可能性（メーカーサイト調査）

### 4.1 前提の訂正

- **エポック社のカプセルトイ事業は自社サイトにない。** 20年以上前に株式会社ターリン・インターナショナルへ移管され、`tarlin-capsule.jp` が実体。`epoch.jp` は HTTP 403
- `www.epoch.jp` / `epoch.co.jp` / `so-ta.jp` は **DNS解決不可**。SO-TA は公式ドメイン特定できず

### 4.2 メーカー別の取得可能性

| 項目 | バンダイ | タカラトミーアーツ | 奇譚クラブ | ターリン | ケンエレファント |
|---|---|---|---|---|---|
| 新商品一覧URL | `/products/`(500件)<br>`/schedule/`(149件) | `/items/gacha/` | `/products/` | `/product` | `/miniature-collection/` |
| 発売日粒度 | **月単位**<br>「2027年1月未定」 | **月単位** | **月＋旬**<br>「9月下旬」 | **月単位** | 記事内記載 |
| 名称/価格/全何種 | 全て取得可 | 全て取得可 | 取得可 | 日付はdescription内 | **商品DBなし** |
| 静的/動的 | **完全な静的SSR**<br>クラス名安定 | **静的HTML** | **静的＋JSON-LD** | Nuxt SPA だが**SSR済み**＋API | WordPress、商品構造なし |
| 機械可読形式 | なし（sitemap.xmlも404） | sitemap.xml あり | **WP REST API**＋sitemap | **公開JSON API**<br>`/api/products` (Strapi) | WP REST API＋RSS<br>（商品post typeなし） |
| robots.txt | **ファイル自体が存在しない**(404) | `User-Agent: *` のみ<br>**Disallow記載ゼロ** | `Disallow: /wp-admin/` のみ | **404（存在しない）** | `Disallow: /wp-admin/` のみ |
| 規約のスクレイピング条項 | 確認できず | 「**無断で転用、転載することはご遠慮ください**」<br>自動取得の明文条項はなし | 確認できず | 確認できず | 確認できず |
| 画像URL形式 | `bandai-a.akamaihd.net/bc/img/model/b/{ID}_2.jpg` | `/upfiles/products/{CODE}_b.jpg` | `/wp-content/uploads/YYYY/MM/` | `/uploads/{size}_*.jpg` | `/wp-content/uploads/YYYY/MM/` |

### 4.3 取得難易度ランク

| ランク | メーカー | 理由 |
|---|---|---|
| **容易** | **奇譚クラブ** | WP REST APIで953件。`X-WP-Total`でページング可 |
| **容易** | **ターリン（旧エポック）** | **公開JSON API `/api/products` が認証なしで全件返す** |
| **容易** | **バンダイ** | APIは無いが500件が完全な静的HTML、CSSクラスが安定 |
| 工夫要 | タカラトミーアーツ | 静的だが一覧が横カルーセルでページングなし。sitemap経由が必要 |
| **困難** | ケンエレファント | 商品専用post typeがなく、情報がニュース記事本文に埋没 |
| 判定不能 | Qualia | 一覧に日付・価格がなく全件巡回が必要 |
| 対象外 | SO-TA | ドメイン特定できず |

**最も取りやすい上位3社: 奇譚クラブ → ターリン → バンダイ**

### 4.4 発売日の粒度についての結論

**月単位が明確に主流。日単位（YYYY年M月D日）の発売日は全メーカーで確認できなかった。**

- バンダイは「2027年1月**未定**」と、日が未定であることを明示的にデータ化
- 奇譚クラブのみ「9月**下旬**」と旬（上/中/下）の粒度あり
- 業界構造上の必然（自販機への配荷のため、日単位の発売日は原理的に存在しない）

→ **DB設計は `YYYY-MM` ＋任意で旬（上旬/中旬/下旬）とし、日単位カラムを持たない。**

### 4.5 実務上の注意点

- **バンダイの月フィルタは機能しない。** `?sale_year=2026&sale_month=09` と `10` で結果が完全同一（先頭JANコード一致、レスポンス520,361バイトで固定）。クライアントサイド処理のため、**全500件を取得してから自前でフィルタする必要がある**
- **robots.txt が「無い」ことは許可の明示ではない。** バンダイとターリンは robots.txt 自体が存在せず、TTAは Disallow ゼロ行。技術的には全面許可だが、**TTAは規約で無断転載を明確に禁じている**
- **商品画像は全社とも版権物。** URLは機械的に取得できるが、再配布はライセンス上の問題が生じる
- アクセスは1リクエスト/秒程度、更新頻度は日次で十分（発売情報が月単位のため）

## 5. 課金の成立性（最も厳しい所見）

### 5.1 隣接市場でサブスクが成立していない

**日本のトレカ管理アプリ市場は、サブスク課金が成立していない。**

| アプリ | 料金モデル | 規模 |
|---|---|---|
| DMMマイカ | **基本無料** | ユーザー18万人超 |
| magi | **基本無料**（販売手数料で収益） | 累計60万インストール |
| カドラバ | 基本無料・広告なし | 非公開 |
| pnote | **完全無料・広告なし** | 非公開 |

→ **国内トレカ管理の上位3アプリはいずれもサブスク非採用。** DMM・magiという資本力のあるプレイヤーが「管理機能は無料、収益は流通から」を確立しているため、**管理機能単体への課金は競争上きわめて不利。**

### 5.2 価格相場

- **My図鑑: 月額350円**（評価4.6/5・1,170件）。買い切りアイテム150〜500円を併売
- 推し活ノート、推し活家計簿: プレミアムあり（価格は確認できず）

**このジャンルの国内サブスク相場は月額350〜500円程度。**
当初想定の「月額500〜1,000円」は相場の上限〜超え。**1,000円は非現実的、500円が上限。**

### 5.3 課金率

- サブスクの課金率（PUR）業界平均: **2〜5%**
- フリーミアムの有料転換率: 2.1%
- 無料トライアル経由の転換率: 10〜29%

### 5.4 有料ユーザー数の推定

| ステップ | 係数 | 母数 | 根拠 |
|---|---|---|---|
| 日本の20〜60代人口 | — | 約7,000万人 | 人口統計 |
| カプセルトイ購入経験者 | 35% | 約2,450万人 | ハピネット調査 |
| 月1回以上の定期購入層 | 63.3% | 約1,550万人 | BANDAI SPIRITS調査 |
| 1回1,000円以上の高支出層 | 15〜20% | **約230〜310万人** | ハピネット調査 |
| 管理したいほど所持数が多い層 | 10〜20%（**推定**） | 約23〜62万人 | ※直接の出典なし |
| アプリで管理する意向がある層 | 30%（**推定**） | 約7〜19万人 | ※推定値 |
| **サブスク課金率** | 2〜5% | **約1,400〜9,300人** | 業界標準PUR |

**理論上の有料ユーザー天井は 1,500〜9,000人規模。**
ただしこれは認知が完全な場合の上限であり、実際には**認知獲得が最大のボトルネック**。

### 5.5 目標月5〜10万円への必要条件

- 有料150〜250人（月額400円換算）
- **必要MAU: 3,000〜12,000人**
- 有料100人（月4万円）でも **MAU 2,000〜5,000人が必要**

## 6. 総合判定と推奨

### 6.1 判定

| 要素 | 判定 | 理由 |
|---|---|---|
| 市場規模 | ◎ | 6年で5倍、専門店1年で200店増、母数は十分すぎる |
| 競合の空白 | ○ | コレクション管理＋交換に明確な空白 |
| 情報の取得可能性 | ○ | 2社は公開API。ただし**週/月単位まで。店舗別入荷日は不可** |
| 課金の成立性 | △ | 相場350〜500円。管理機能単体では課金困難 |
| 目標月5〜10万 | △ | MAU 3,000〜12,000 が必要 |

**結論: 条件付きGO。ただし当初構想からの軸移動が必須。**

### 6.2 やってはいけないこと

- ❌ **入荷情報・入荷日予測を主軸にする** — 情報が存在せず精度を約束できない。競合も飽和。先行者が失敗済み
- ❌ **設置場所・在庫検索** — 公式3社（バンダイ/TTA/ハピネット）が無料提供。特にgashacocoのPOS連動は個人開発では再現不可能
- ❌ **月額500円超の価格設定** — 相場超え
- ❌ **配送・決済の仲介** — 運営コストが無限大

### 6.3 勝ち筋

1. **ラインナップ単位のコレクション管理**（全5種中3種所持、シークレット未所持）— 最大の空白
2. **ダブり交換マッチング** — ハピネットは構造上やれない（自社売上を食う）、無料トレカアプリにもない
3. **メーカー横断** — 公式は自社商品しか扱えない

ターゲットは**20〜30代女性の専門店来店層**（来店率78.6%、ガチャガチャの森利用者の6割が女性、SNS映え意識が7.1%→12.5%と倍増中）。X/Instagramでの獲得と相性が良い。

### 6.4 成否を分ける3点

1. **無料競合と戦わない機能設計**
2. **相場に合わせた価格（500円未満）**
3. **数千MAUを集める集客力** ← 技術ではなくここが最難関
